# Platinum song catalog

Public host for the Platinum app's song catalog. `catalog.json` lists the songs; files are in `songs/`.
Format and rules: see `docs/CATALOG.md` in the Platinum app repository.

The two demo songs (1 and 2) are original, generated tones with original lyrics, made for testing. They have no copyright restrictions.
Only add songs here that you have the right to distribute.
